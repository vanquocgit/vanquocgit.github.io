## 1. Tóm tắt nội dung Vlog

Đây là bài đăng mẫu cho định dạng **Vlog**. Ở phần khai báo đầu file (`youtubeId`), khi bạn điền ID video YouTube, giao diện sẽ tự động hiển thị trình phát video nhẹ phía trên bài viết và gắn nhãn **Vlog** ngoài danh sách.

<Callout type="info" title="Tối ưu tốc độ tải trang">
  Khung video ở trên chỉ hiển thị ảnh thu nhỏ nhẹ ban đầu. Trình phát iframe của YouTube chỉ được tải khi người đọc bấm nút Play.
</Callout>

## 2. Ghi chú và câu lệnh thực hành

Dưới đây là một số lệnh thường dùng khi kiểm tra và chạy web ở máy cá nhân:

```bash
# Chạy server phát triển ở localhost
npm run dev

# Kiểm tra lỗi TypeScript và build thử bản sản phẩm
npm run build
```

## 3. Tổng kết

Kết hợp video giải thích trực quan cùng văn bản tóm tắt giúp người xem dễ tra cứu lại câu lệnh và giúp Google Search lập chỉ mục nội dung chính xác hơn.
